# Vier-Gewinnt Pilot (Java + AWT)

Ein einfacher erster Pilot mit:
- Ballon-Startbildschirm mit Sprachumschaltung
- 7x6 Spielfeld
- Zwei Spieler (Rot/Gelb)
- Optionaler Computergegner
- Gewinnpruefung in alle Richtungen
- Unentschieden-Erkennung
- Reset-Button fuer neues Spiel

## Projektstruktur

- Quellcode liegt unter `src/`
- Einstiegspunkt ist `com.project.Main`
- Kompilate liegen unter `bin/`

## Starten

### Windows

1. Kompilieren:

```cmd
build.bat
```

2. Ausfuehren:

```cmd
run.bat
```

### Linux/macOS

1. Kompilieren:

```bash
./build.sh
```

2. Ausfuehren:

```bash
./run.sh
```
